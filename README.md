# 基于深度强化学习的A股投资组合交易系统

## 项目概述

本项目使用 PPO（Proximal Policy Optimization）强化学习算法，构建一个面向 A 股市场的多资产投资组合交易智能体。环境模拟了 A 股的主要交易约束（T+1、不可卖空、佣金、印花税、滑点），并在沪深300成分股上完成训练与样本外回测。

项目的重要价值不在于策略收益本身，而在于完整展示了一次真实的研究过程：**从初版异常高收益，到排查发现未来函数，再到修复后客观评估模型能力上限**。

## 数据来源

- 行情数据：Baostock（后复权日线收盘价）
- 股票池：沪深300成分股中数据最完整的 20 只
- 数据区间：2021-01-04 至 2023-12-29
- **选股仅使用训练期（2021-2022）数据判断完整性，避免幸存者偏差**

## 环境设计

### 状态空间（4N+1 维，N=20）
- 每只股票 3 个技术指标：20日动量、20日波动率、价格偏离度（当前价/20日均价-1）
- 当前每只股票的持仓权重（N 维）
- 当前现金权重（1 维）
- **所有特征只使用 t-1 及之前的数据，严格避免未来函数**

### 动作空间
- 长度为 N+1 的连续向量：前 N 个为目标股票权重，最后一个为目标现金权重
- 归一化后总和为 1，权重非负（不可卖空）

### 交易约束
- **T+1**：当日买入的股票次日才能卖出
- **交易成本**：佣金万三（双边）、印花税千一（卖出）、滑点千一
- 组合净值初始为 1

### 奖励函数
- 最终版本：对数收益 `log(1 + 组合日收益 - 交易成本率)`
- 曾尝试滚动夏普比率作为奖励以控制回撤，但模型过度保守，收益接近零，故回退

## 训练设置

| 项目 | 设置 |
|------|------|
| 算法 | PPO (stable-baselines3) |
| 策略网络 | MlpPolicy（全连接） |
| 训练集 | 2021-01-04 ~ 2022-12-30（485个交易日） |
| 测试集 | 2023-01-03 ~ 2023-12-29（242个交易日） |
| 训练步数 | 100,000 |
| 学习率 | 3e-4 |
| 折扣因子 | 0.99 |

## 研究过程与关键发现

### 1. 初版结果异常：年化 301%
初次训练后，策略在测试集上年化收益 301%，夏普 4.21。这一结果远超正常水平，触发排查。

### 2. 排查过程
- **交易成本检查**：平均每步调仓成本 0.0565%，成本计算正常，排除免费交易嫌疑。
- **随机策略基线**：随机动作年化 0.36%，环境基本公平，排除环境漏洞。
- **短训练对比**：30,000 步模型年化 106%，说明不是单纯训练步数过拟合。
- **定位根因**：`_get_obs()` 中价格偏离度使用了第 t 天收盘价，而 `step()` 又用 t 天价格计算 t 天收益，相当于**每天收盘前就知道当日涨跌**，存在未来函数。

### 3. 修复后结果
修正为状态只使用 t-1 及之前的数据，并调整 `step()` 中时间推进与收益计算的顺序后：

| 指标 | 策略 | 等权基准 |
|------|------|---------|
| 年化收益 | 13.04% | 32.46% |
| 夏普比率 | 0.56 | 1.51 |
| 最大回撤 | -34.64% | -19.57% |

### 4. 进一步尝试
将奖励函数改为滚动夏普比率以控制回撤，回撤收窄至 -27.63%，但年化降至 -1.61%，模型过度保守。最终回退到对数收益版本，接受 13.04% 的结果。

## 结论与局限

- 修复未来函数后，PPO 策略年化 13.04%，跑输等权基准（32.46%），说明在当前特征和样本规模下，强化学习难以稳定跑赢简单基准。
- 主要局限：
  - 状态特征仅 3 个技术指标，信息量有限
  - 训练样本仅 485 个交易日、20 只股票，PPO 在高维动作空间上容易过拟合
  - 未引入市场状态变量（如指数趋势、宏观因子）
  - 未做滚动训练与多随机种子平均

## 未来优化方向

- 增加市场状态特征（指数动量、波动率、行业轮动信号）
- 使用滚动窗口训练与多随机种子集成，降低过拟合
- 尝试 SAC、TD3 等更适合连续动作空间的算法
- 引入风险预算或分层动作空间，替代直接输出全组合权重
- 在更大股票池（50-100只）上验证策略稳健性
